Repositories

Update each repository to its remote default branch. Integration patches are reapplied; model and user files are preserved.

Model downloads

These checks report checkpoint files on disk. IndexTTS 2.0 is the default backend; other models load into GPU memory on demand. A downloaded model can still be unloaded or sleeping. Use the GPU studio's Model Manager to check live model state. Confucius downloads include conversion for vLLM.

Component environments · included in image

Dependencies are installed when the Modal image is built, as before. Rebuild and redeploy the image to change them.
