                                        GET
                                        /api/stable-audio/models
                                    

                                    

                                        
List Stable Audio 3 variants, checkpoint readiness, and
                                            loaded model state.

                                    

                                

                                

                                    

                                        POST
                                        /api/stable-audio/generate
                                    

                                    

                                        
Generate music or sound effects. Uses Stable Audio 3 Medium
                                            by default.

                                        

                                            

                                                
Required

                                                
prompt string - Audio description

                                            

                                            

                                                
Optional

                                                
variant_key
                                                    string - medium, small-music, or
                                                        small-sfx
                                                

                                                
batch_count
                                                    int - Generate 1-4 clips in parallel. Count 1
                                                        returns an audio attachment; counts 2-4 return JSON with base64
                                                        audio items.
                                                

                                                
duration,
                                                    steps, cfg_scale, sampler_type, seed - Sampling controls
                                                

                                                
init_audio_file, inpaint_audio_file file - Optional audio-to-audio and inpainting
                                                        inputs

                                            

                                        

                                        

                                            
Response

                                            
Content-Type: audio/mpeg
                                                Content-Disposition: attachment; filename=stable_audio_medium.mp3

                                                For batch_count 2-4:
                                                Content-Type: application/json
                                                { "status": "success", "items": [{ "filename": "...", "media_type":
                                                "audio/mpeg", "audio_base64": "..." }] }

Speech Generation

                                Core API
                            

                            

                                
                                

                                    

                                        POST
                                        /speak
                                    

                                    

                                        
Generate speech using a registered speaker preset. Supports
                                            emotion control, text splitting, and optional stacked speaker effects.

                                        

                                            

                                                
Required Parameters

                                                
text string — Text to synthesize

                                                
name string — Speaker preset name

                                            

                                            

                                                
Optional Parameters

                                                
emotion_text
                                                    string — Emotion description (e.g., "happy and
                                                        excited")
                                                

                                                
emotion_weight float — Emotion intensity 0.0-1.0 (default:
                                                        0.6)

                                                
diffusion_steps int —
                                                        Quality steps (default: 10)

                                                
max_text_tokens_per_sentence int —
                                                        Text splitting threshold 80-200 (default: 120)

                                                
speaker_effects string[] — Optional ordered effects, e.g.
                                                        ["phone_call", "reverb_small_room"]

                                            

                                        

                                        

                                            
Response

                                            
Content-Type: audio/mpeg
                                                Binary MP3 audio data

                                        

                                    

                                


                                
                                

                                    

                                        POST
                                        /clone_voice
                                    

                                    

                                        
Clone voice using uploaded reference audio (zero-shot voice
                                            cloning).

                                        

                                            

                                                
Required Parameters
                                                    (multipart/form-data)

                                                
text string — Text to synthesize

                                                
reference_audio_file file — Reference audio for voice
                                                        cloning

                                            

                                            

                                                
Optional Parameters

                                                
emotion_text,
                                                    emotion_weight, diffusion_steps, max_text_tokens_per_sentence,
                                                    speaker_effects — Same as /speak
                                                

                                            

                                        

                                    

                                


                                
                                

                                    

                                        POST
                                        /speak_stream
                                    

                                    

                                        
Generate speech with streaming chunks for low-latency
                                            playback.

                                        

                                            

                                                
Parameters

                                                
Same as
                                                        /speak

                                            

                                        

                                        

                                            
Streaming Response Format

                                            
CHUNK:{idx}:{size}:{status}\n{audio_bytes}

                                                Status: MORE (more chunks) or LAST (final chunk)

                                        

                                    

                                


                                
                                

                                    

                                        POST
                                        /clone_voice_stream
                                    

                                    

                                        
Clone voice with streaming output. Same parameters as
                                            /clone_voice, same streaming format as /speak_stream.

                                    

                                


                                
                                

                                    

                                        GET
                                        /speaker_effects
                                    

                                    

                                        
List optional speaker effect IDs, names, descriptions, and

Speech Translation

                                Gemini-Powered
                            

                            

                                
                                

                                    

                                        POST
                                        /api/translate_audio
                                    

                                    

                                        
One-shot speech translation. Translates audio and
                                            regenerates voice in the target language while preserving timing.

                                        

                                            

                                                
Required (multipart/form-data or
                                                    JSON)

                                                
audio_file
                                                    file — Source audio file
                                                

                                                
dest_language
                                                    string — Target language (e.g., "English",
                                                        "Chinese")
                                                

                                            

                                            

                                                
Audio Separation (Vocal/Instrumental)
                                                

                                                
audio_separator_enabled bool — Enable audio-separator for
                                                        vocal/instrumental separation (recommended for backing
                                                        track)

                                                
audio_separator_model string — Model: 'fast' (UVR-MDX-NET), 'balance'
                                                        (default, BS-Roformer), or 'quality' (Mel-Band-Roformer)
                                                

                                                
audio_separator_use_soundfile
                                                    bool — Use soundfile writer for separated
                                                        stems (slower fallback; default false)
                                                

                                            

                                            

                                                
ClearVoice Enhancement

                                                
enhance_voice
                                                    bool — Enable voice enhancement (applied to
                                                        vocals)
                                                

                                                
enhancement_model string — Model: 'MossFormerGAN_SE_16K'
                                                        (default), 'FRCRN_SE_16K', or 'MossFormer2_SE_48K'

                                                
super_resolution_voice bool — Enable 48kHz super resolution
                                                

                                                
merge_backing_track bool — Blend with instrumental (requires
                                                        audio_separator_enabled)

                                            

                                            

                                                
Advanced Options

                                                
prompt string — Custom Gemini instructions

                                                
transcription_pipeline string — 'moss_transcribe' (default), 'gemini',
                                                        'whisperx', 'qwen_omnivad', or 'parakeet'

                                                
translation_llm_model string — Translation model:
                                                        'tencent/Hy-MT2-1.8B' (default), 'lightning-ai/gemma-4-31B-it',
                                                        'lightning-ai/gpt-oss-20b', 'lightning-ai/gpt-oss-120b', or
                                                        'lightning-ai/minimax-m2.5'

                                                
whisperx_proxy_refiner bool — Enable WhisperX proxy refiner (default
                                                        false)

                                                
qwen_omnivad_enable_forced_aligner
                                                    bool — Enable Qwen ForcedAligner timestamps
                                                        (default true)
                                                

                                                
qwen_omnivad_enable_diarization
                                                    bool — Enable diarization for Qwen OmniVAD
                                                        (default true)
                                                

                                                
qwen_omnivad_diarization_backend
                                                    string — 'auto', 'pyannote', or 'sortformer'
                                                        (Sortformer fallback when no HF token)
                                                

                                                
qwen_omnivad_merge_gap_seconds
                                                    float — Merge adjacent OmniVAD spans separated
                                                        by this many seconds (default 0.001)
                                                

                                                
segments_json
                                                    string — Pre-generated Gemini segments (skip
                                                        inference)
                                                

                                                
min_speech_ms
                                                    / max_merge_ms int —
                                                        Segment merging heuristics

                                            

                                        

                                        

                                            
Response Headers

                                            
X-Translation-Model: gemini-flash-latest
                                                X-Translation-Segments: [{"start": "00:00", "end": "00:05", ...}]
                                                Content-Type: audio/mpeg

                                        

                                    

                                


                                
                                

                                    

                                        POST
                                        /api/translate_segments
                                    

                                    

                                        
Prepare editable translation segments for the advanced
                                            translate/edit workflow. Returns a session with diarized, editable segments.
                                        

                                        

                                            

                                                
Key Parameters

                                                
audio_file
                                                    file — Source audio
                                                

                                                
dest_language
                                                    string — Target language (required)
                                                

                                                
translate_text bool — true=translate, false=transcribe
                                                        only

                                                
transcription_pipeline string — 'moss_transcribe' (default), 'gemini',
                                                        'whisperx', 'qwen_omnivad', or 'parakeet'

                                                
translation_llm_model string — Translation model:
                                                        'tencent/Hy-MT2-1.8B' (default), 'lightning-ai/gemma-4-31B-it',
                                                        'lightning-ai/gpt-oss-20b', 'lightning-ai/gpt-oss-120b', or
                                                        'lightning-ai/minimax-m2.5'

                                                
whisperx_proxy_refiner bool — Enable WhisperX proxy refiner (default
                                                        false)

                                                
qwen_omnivad_enable_forced_aligner
                                                    bool — Enable Qwen ForcedAligner timestamps
                                                        (default true)
                                                

                                                
qwen_omnivad_enable_diarization
                                                    bool — Enable diarization for Qwen OmniVAD
                                                        (default true)
                                                

                                                
qwen_omnivad_diarization_backend
                                                    string — 'auto', 'pyannote', or 'sortformer'
                                                        (Sortformer fallback when no HF token)
                                                

                                                
qwen_omnivad_merge_gap_seconds
                                                    float — Merge adjacent OmniVAD spans separated
                                                        by this many seconds (default 0.001)
                                                

                                                
gemini_model
                                                    string — Model selection (flash/pro)
                                                

                                                
reuse_session_id string — Reuse audio from previous
                                                        session

                                                
default_speaker_preset string — Default voice for all speakers
                                                

                                            

                                        

                                        

                                            
SSE Stream Events

                                            
{"event": "status", "stage": "gemini", "message":
                                                "..."}
                                                {"event": "complete", "session_id": "...", "segments": [...],
                                                "metadata": {...}}

Batch Audio Processing

                                Long Audio
                            

                            

                                
                                

                                    

                                        POST
                                        /api/translate_split_audio
                                    

                                    

                                        
Split long audio into ClearVoice-enhanced chunks at silence
                                            points for parallel processing.

                                        

                                            

                                                
Chunk Settings

                                                
chunk_min_minutes float — Minimum chunk length (default:
                                                        3)

                                                
chunk_max_minutes float — Maximum chunk length (default:
                                                        6)

                                                
min_silence_ms int —
                                                        Minimum silence for split (default: 2000)

                                                
silence_threshold_db float — Silence detection threshold (default:
                                                        -40)

                                            

                                        

                                        

                                            
Final Event

                                            
{"event": "complete", "chunk_batch_id": "...",
                                                "chunk_sessions": [{"session_id": "...", "chunk_index": 0, ...}]}

                                        

                                    

                                


                                
                                

                                    

                                        POST
                                        /api/translate_generate_chunks
                                    

                                    

                                        
Generate translated audio for multiple chunk sessions in
                                            parallel.

                                        

                                            

                                                
JSON Body

                                                
chunk_session_ids array — Array of session IDs to process
                                                

                                                
dest_language
                                                    string — Target language
                                                

                                                
transcription_pipeline string — 'moss_transcribe' (default), 'gemini',
                                                        'whisperx', 'qwen_omnivad', or 'parakeet'

                                                
translation_llm_model string — Translation model:
                                                        'tencent/Hy-MT2-1.8B' (default), 'lightning-ai/gemma-4-31B-it',
                                                        'lightning-ai/gpt-oss-20b', 'lightning-ai/gpt-oss-120b', or
                                                        'lightning-ai/minimax-m2.5'

                                                
whisperx_proxy_refiner bool — Enable WhisperX proxy refiner (default
                                                        false)

                                                
qwen_omnivad_enable_forced_aligner
                                                    bool — Enable Qwen ForcedAligner timestamps
                                                        (inherits session; default true)
                                                

                                                
qwen_omnivad_enable_diarization
                                                    bool — Enable diarization for Qwen
                                                        OmniVAD
                                                

                                                
qwen_omnivad_diarization_backend
                                                    string — 'auto', 'pyannote', or

                                                    float — Merge adjacent OmniVAD spans separated

Get default Gemini prompt templates for translation and
                                            transcription.

                                        

                                            
Response

                                            
{"translation": "You are a professional
                                                interpreter...",
                                                "transcription": "Transcribe the provided speech...",
                                                "ignore_non_speech_instruction": "..."}

                                        

                                    

                                


                                

                                    

                                        POST
                                        /api/estimate_duration
                                    

                                    

                                        
Estimate speech duration from text before generation.

                                        

                                            

                                                
JSON Body

                                                
text string — Text to estimate

                                                
language
                                                    string — Language code or "auto"
                                                

                                            

                                        

                                    

                                


                                

                                    

                                        POST
                                        /api/clear_outputs
                                    

                                    

                                        
Clear all generated output files and free disk space.

Basic Speech Generation

                            
# Python
                                import requests

                                response = requests.post("http://localhost:8080/speak", json={
                                "text": "Hello, how are you today?",
                                "name": "speaker1",
                                "emotion_text": "cheerful and friendly",
                                "emotion_weight": 0.7,
                                "speaker_effects": ["phone_call", "reverb_small_room"]
                                })

                                with open("output.mp3", "wb") as f:
                                f.write(response.content)


                            
One-Shot Translation

                            
# Python
                                import requests

                                with open("source_audio.mp3", "rb") as f:
                                response = requests.post(
                                "http://localhost:8080/api/translate_audio",
                                files={"audio_file": f},
                                data={
                                "dest_language": "English",
                                "enhance_voice": "true",
                                "merge_backing_track": "true"
                                }
                                )

                                with open("translated.mp3", "wb") as f:
                                f.write(response.content)

Voice Design (Qwen3-TTS)

                            
# Python - Generate with voice description
                                import requests

                                response = requests.post("http://localhost:8080/api/design-voice", json={
                                "text": "Welcome to our platform!",
                                "voice_description": "A warm, friendly female voice with a British accent",
                                "language": "English"
                                })

                                with open("designed_voice.mp3", "wb") as f:
                                f.write(response.content)

                                # Save to presets for reuse
                                requests.post("http://localhost:8080/api/design-voice/save-preset", json={
                                "preset_name": "british_female",
                                "description": "Warm British female voice"
                                })
